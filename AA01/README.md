## 🌐 Overview
Agent Anna (`AA01`) is an autonomous multi-agent matrix and real-world asset (RWA) ecosystem. ---

## 🚀 Architecture & Features
* **Zero Server Overhead:** Built on serverless principles and GitHub Pages. Zero hosting fees, zero single points of failure.
* **ET-Neural Interface:** High-contrast cyberpunk UI featuring pulsing neural network lines and state-of-the-art visual telemetry.
* **Live Market Charts:** Integrated real-time charting toggling between Dogecoin liquidity baselines and the 8-month SHI* utility seed curve.
* **Bot-Proof P2P Exchange:** Off-chain signed PSBTs combined with client-side Proof-of-Work challenges to eliminate sandwich attacks and mempool front-running.
